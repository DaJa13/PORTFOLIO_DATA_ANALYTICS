# Структура данных проекта CRM

Проект основан на CRM-системе компании, которая занимается оформлением сертификатов соответствия для юридических лиц.
Схема упрощена и включает только таблицы, которые использовались в анализе.

---

## crm_company
Основная таблица с клиентами (компаниями).

Поля:
- id — идентификатор компании
- name — название компании
- email — контактный email
- date_issue — дата выдачи сертификата

Используется в анализе:
- база для всех SQL-запросов
- сегментация клиентов
- анализ активности

---

## crm_payments
Платежи клиентов.

Поля:
- id — идентификатор платежа
- company__id — связь с таблицей компаний
- amount — сумма платежа

Используется в анализе:
- выручка по компаниям
- средний чек
- количество платежей
- повторные клиенты

---

## crm_contact
Контакты компаний.

Поля:
- id
- company__id

Использовалась в анализе клиентской базы (общее количество контактов по компаниям)

---

## crm_reminder
Напоминания и задачи по клиентам.

Поля:
- id
- company__id

Использовалась как косвенный показатель активности работы с клиентами

---

## crm_view_certificate
Справочник типов сертификатов.

Поля:
- id
- name

Используется в анализе:
- прибыльность по типам сертификатов
- сегментация клиентов по продукту

---

## Связи между таблицами

crm_company — центральная таблица

- crm_company → crm_payments (1 ко многим)
- crm_company → crm_contact (1 ко многим)
- crm_company → crm_reminder (1 ко многим)
- crm_company → crm_view_certificate (many-to-one через company)

---

## Примечание

Схема упрощена и отражает только те таблицы, которые использовались в аналитических запросах проекта.
