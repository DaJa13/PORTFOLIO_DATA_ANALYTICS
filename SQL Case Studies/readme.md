# CRM SQL Analytics Project

## Описание
Проект основан на анализе данных CRM-системы компании, занимающейся оформлением сертификатов соответствия и разрешительной документации для юридических лиц.
CRM включает данные о компаниях-клиентах, платежах, контактах, напоминаниях и сертификатах и их сроке действия.
Цель проекта — получение бизнес-инсайтов через SQL-аналитику и анализ клиентской активности.

## Используемые технологии
- SQL (PostgreSQL)
- JOIN (INNER / LEFT)
- GROUP BY
- HAVING
- CASE
- Window Functions
- CTE

## Структура данных

Основные таблицы проекта:
- crm_company — компании-клиенты
- crm_payments — платежи клиентов
- crm_contact — контакты компаний
- crm_reminder — напоминания и задачи
- crm_view_certificate — типы сертификатов

## Метрики и анализ

В рамках проекта были рассчитаны:

- выручка по компаниям
- средний чек
- количество платежей
- клиентская активность
- сегментация клиентов (VIP / Medium / Low)
- анализ клиентской активности и повторных продаж
- анализ потенциального оттока клиентов
- прибыльность сертификатов по типам
- контроль сроков истечения сертификатов

## Основные выводы

- Выделены ключевые клиенты, формирующие основную выручку
- Проведена сегментация компаний по уровню дохода
- Определены компании с низкой активностью
- Проанализирован потенциальный отток клиентов
- Определены наиболее прибыльные направления

## Навыки

Проект демонстрирует:
- работу с реальной структурой CRM
- построение аналитических SQL-запросов
- понимание бизнес-метрик
- работу с JOIN, агрегациями и оконными функциями
- базовую продуктовую аналитику
  
Проект моделирует типовые задачи Data Analyst в B2B-компании:
анализ клиентской базы, выручки, повторных продаж, удержания клиентов и операционных метрик.
